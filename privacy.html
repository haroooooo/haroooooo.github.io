プライバシーポリシー

nemuri-uploader（以下「本ツール」）は、開発者本人が自分の YouTube チャンネルへ動画を投稿するためだけに使う個人用ツールです。

取得する情報

開発者本人が Google アカウントでログインして許可した範囲で、YouTube への動画のアップロードと、タイトル・説明・サムネイルなどの設定（YouTube Data API）を行います。

情報の利用と共有

  • ログイン情報（トークン）は、開発者本人の動画を投稿する目的にのみ使います。
  • 第三者への提供、販売、広告への利用は行いません。
  • 開発者以外の個人情報は収集しません。

保管と取り消し

ログイン情報は、開発者が管理する環境にのみ保管します。開発者は、Google アカウントの設定からいつでも許可を取り消せます。

Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。
